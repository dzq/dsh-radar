## 🏆 头部插件：这三个值得关注

**① dshmarket — S 级 · 11,862 dl/wk**

本周下载量最高的插件，没有之一。

它的定位很有意思：做一个「插件版 App Store」。你不需要记住 npm install，只需要打开它，搜索，点安装。生态还在野蛮生长时，这种「入口级」插件永远是刚需。

👉 radar.aidzq.cn/plugins/dshmarket

---

**② dsh-pocket — S 级 · 4,381 dl/wk**

我最喜欢的插件之一。

它解决了一个很具体的问题：你在外面，突然想看看 DSH 里跑的任务进展。以前要掏电脑，现在手机扫码就能看会话、查进度、甚至继续对话。体验丝滑程度，用过就知道了。

👉 radar.aidzq.cn/plugins/dsh-pocket

**③ @liustack/modsearch — S 级 · 4,097 dl/wk**

LLM 大模型没有原生联网能力，这个插件帮你解决。

它把网页搜索能力接进来，支持 Bing、Google、Perplexity 等主流引擎。配 GPT-4 或 Claude 直接用，效果比原生的 browsing 强一个档次。104 个 GitHub Stars，也是社区认可度的证明。

👉 radar.aidzq.cn/plugins/liustack--modsearch

## 💡 本周三个趋势

**趋势一：应用层插件开始冒头**

这周入库的插件里，「remote」「browser」「deep-read」这类**场景型插件**明显比纯工具型多了。

之前生态里最多的是文件处理、API 调用这类基础能力。现在开始有人在上面搭应用了——这是生态走向成熟的信号。

**趋势二：移动端需求被验证**

dsh-pocket 的持续高热说明「手机操控 DSH」不是伪需求。随着 DSH 普及，这个场景会越来越强。

**趋势三：安全意识觉醒**

dsh-plugin-vetting（代码审计插件）本周新晋 Top10，说明用户在大量安装插件之后，开始有人关心「这个插件安不安全」了。这是生态自我纠错的开始。
