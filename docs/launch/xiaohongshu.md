# 小红书笔记

## 标题（20 字内 · emoji 党）

🎯 **DSH 711 个插件，我只敢装 4 个** 🔥

## 正文（600-900 字 · 朋友聊天风）

姐妹们（也可能是兄弟们），今天说个让我崩溃的事 😭

我最近在用 DSH（DeepSeek Harness）搭 workflow，npm 上搜 `dsh-plugin` 一看 —— **711 个包**。

711 个啊朋友们。选插件选到眼花。

然后我就想：总得有人告诉我**哪个能用**吧？结果一查，全网都是 awesome 列表、插件市场、罗列罗列罗列……

**没有一个人告诉我：哪个好用。**

崩溃。

于是我干脆自己做了一个 —— **DSH Radar**（dsh.pub）。

---

**🎯 它干了啥？**

把 711 个插件全部跑了一遍评分，按 S/A/B/C/D 分级。

结果嘛……**很真实**：

- **S 级**：1 个（@liustack/modsearch）
- **A 级**：3 个（pptfast / design-playbook / plaindeck）
- **B 级**：147 个
- **C 级**：549 个 ← 主流
- **D 级**：11 个 ← **高危，建议直接禁掉**

朋友们，711 个里真正能放心装的只有 **4 个**。剩下 91% 都是 B 和 C。

剩下的 11 个 D 级……emmm，你们品品。

---

**🛠️ 技术栈（开发者时间）**

- 纯 Node 18 内置 fetch，**零依赖**，22 分钟跑完全量
- Astro 5 静态站，919 个页面，build **920ms**
- 雷达图是手写 SVG，没有 chart 库依赖（强迫症发作）
- 客户端 JS 搜索，URL 同步：`?q=xxx&grade=A&sort=w`

---

**✨ 不只是评分，还做了 4 个市场不做的事**

1. **兼容矩阵**：升级 DSH 之前先看一眼哪些会炸 💣
2. **配方库**：直接告诉你「做 PPT 用哪几个插件组合」（省得你试错）
3. **踩坑 Wiki**：自动聚合 GitHub / V2EX / linux.do 上的吐槽贴
4. **横评**：DSH vs BitFun vs Claude Code vs Cursor（6 维雷达）

---

**💰 商业化（很克制）**

个人查看完全免费，**MIT 开源，零追踪**。

团队版 **$19/seat/月**：白名单 / 审计日志 / 私有 registry。

（说真的，企业不让员工随便装插件这事，太真实了 😂）

**最后自嘲一下**：

做这个的本意是「帮大家避坑」。
结果发现 **最大的坑是 D 级插件占 1.5% 这个事实本身**。

装插件这事，到头来确实**靠运气** 🎰。
升级一次 DSH？**像拆炸弹** 💣。
装错一个插件？**整个 workflow 原地爆炸** 💥。
